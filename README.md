# 🎬 Resenha de Filme — Whiplash

Página web desenvolvida em **HTML** para apresentar informações e uma breve resenha sobre o filme **Whiplash — Em Busca da Perfeição**.

## 📖 Sobre o projeto

O projeto foi desenvolvido como uma atividade para praticar os conceitos básicos de **HTML5**, utilizando diferentes elementos para estruturar uma página web.

A página apresenta informações sobre o filme, uma imagem, uma sinopse e um link para mais informações no IMDb.

## 🎥 Informações do filme

* **Filme:** Whiplash — Em Busca da Perfeição
* **Ano:** 2014
* **Diretor:** Damien Chazelle
* **Duração:** 1h 46min
* **Classificação:** 14 anos
* **Gênero:** Drama e Musical
* **País:** Estados Unidos

## 🛠️ Tecnologias utilizadas

* HTML5
* Visual Studio Code

## 📌 Elementos HTML utilizados

Durante o desenvolvimento foram utilizados elementos como:

* `<h1>` — título principal
* `<h2>` — informações sobre o filme
* `<img>` — imagem do filme
* `<p>` — sinopse
* `<a>` — link para o IMDb
* `<head>` e `<body>` — estrutura da página
